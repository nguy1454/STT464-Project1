# STT464-Project1
This repository contains all the code used in the STT 464 Project 1

# Description

Context for the .csv data
This is wheat yield data, split into 4 repetitions with 12 treatments per repetition. There are three variables: row width (5 and 7 inches), wheat variety (Marlin and Wharf), and herbicide treatment timing (untreated, fall-applied Huskie+Osprey, spring-applied Huskie+Osprey). You will see that there is not every plot number, but that’s fine I simplified the treatments down from 20 to 12, so there will be missing plots per rep. It doesn’t change anything. For this, we were looking for whether the wheat yield was affected by row width, variety, herbicide treatment, or any combination of them.
